# Nova PC Browser

Aplicación de escritorio Electron con una interfaz propia y navegación web integrada.

## Crear el instalador
El flujo de GitHub Actions crea el instalador para Windows. Abre la pestaña **Actions**, ejecuta **Build Nova PC for Windows** y descarga el artefacto `Nova-PC-Windows-x64` cuando termine correctamente.

## Importante
- Se necesita conexión a internet para visitar páginas web.
- La aplicación utiliza Electron, que incorpora Chromium; no necesita instalar Chrome, Edge ni Brave como aplicaciones separadas.
- Algunas páginas pueden restringir la reproducción o la navegación dentro de navegadores integrados.
